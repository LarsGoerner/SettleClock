# SettleClock

A simple timer application using a 4.26" e-paper display to show the
remaining number of days between the current date and a given date in the
future.

For training purposes, the software was build from scratch not utilizing cmsis.

## Prerequities

### Toolchain

This project uses the Arm GNU Toolchain *arm-none-eabi*.

### Programmer

A ST-LINK/V2 is used in this project to program/debug the device.
